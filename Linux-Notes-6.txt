Filesystem: Filesystem is an writable location for storing the data into disk.
=============================================================================================================================
Windows:  Local disk  - C:\> drive - filesystem

Linux: Primary disk - "/" or root filesystem

Primary disk: Boot disk - OS is installed - created when machine is launched.
   / - root filesystem
     - /root - home directory for root(admin/super) user
     - /home - home directory for regular users
     - /bin - binaries
     - /lib - libraries
     - /dev - devices
     - /opt - 3rd party softwares
     - /mnt - temporary space for users
     - /tmp - temporary space for systems
     - /usr - unix resources( binaries, libraries, in-build packages etc)
     - /proc - resources(cpu, ram )
     - /media - videos, audio, images etc
     - /boot - OS kernel files, initramfs etc
     - /etc - system configuration files

Secondary disk: Additional disk - Data and Application 
        * Create volume(disk)
        * Attach volume to machine
        * Partitioning(dividing disk into parts)
        * Formatting - blocks(super, inode, journalctl etc)
        * Create filesystem( eg: /app, /app/devops, /data/ops etc)
        * Mounting - Mapping disk with filesystem

Package Management: Software Management
===========================================================================================================================
Windows: .exe(executables) -> double click -> Follow the instructions.

Linux: 
   Redhat: .rpm(redhat package manager) -> Execute command -> RPM - Redhat Package manager
                                                              YUM - Yellow dog update modifier

   Debian: .deb(debian) -> Execute command -> apt - advanced packaging tool


1. RPM: Redhat package manager
        RPM is used since earlier versions of linux and still we are making use of it.
        RPM allows us to install single package at a time.
        Using RPM, we can install, uninstall, upgrade the package.
        For RPM installation, we need to download the package then install it.
        RPM doesn't resolve, download and install dependent packages automatically, we need to manually resolve, download and install dependent packages.
         eg: httpd-2.5.1-1.1.el9.x86_64.rpm       // Install httpd
               Error: httpd-tools package not found
                   httpd-tools-2.5.1-1.1.el9.x86_64.rpm       // Install httpd-tools
                        Error: httpd-security package not found
                           httpd-security-2.5.1-1.1.el9.x86_64.rpm       // Install httpd-security
        We need to mention full path and complete package name at the time of installation.

URL: https://archives.jenkins-ci.org/redhat-stable/

command: curl -O https://archives.jenkins-ci.org/redhat-stable/jenkins-2.263.1-1.1.noarch.rpm
         rpm -ivh jenkins-2.263.1-1.1.noarch.rpm                       // install package
         rpm -qa                                                       // Query all  / list all installed packages
         rpm -qa | grep -i jenkins                                     // Filter and list installed package
         rpm -qi jenkins-2.263.1-1.1.noarch                            // query information
         rpm -ql jenkins-2.263.1-1.1.noarch                            // query list all locations
         
         curl -O https://archives.jenkins-ci.org/redhat-stable/jenkins-2.263.4-1.1.noarch.rpm
         rpm -Uvh jenkins-2.263.4-1.1.noarch.rpm                       // Upgrade the package
         rpm -e jenkins-2.263.4-1.1.noarch                             // Remove/upgrade package

-i install
-v verbose(detailed output)
-h hash - % of completion 
-U upgrade

grep - filter the content/file/directory/software
  -i casesensitive 
| - pipe - forward output of one command as input to another command.

2. YUM: Yellow dog update modifier
        YUM is used since 5.x version of linux OS and still we are making use of it.
        YUM allows us to install more than one package at a time.
        Using YUM, we can install, uninstall, upgrade the package.
        For YUM installation, we just need to install the package and yum will download the package at the time of installation automatically.
        YUM also resolves, downloads and installs all the dependent packages automatically, before installing actual package.
        We dont need to mention full path and complete package name at the time of installation.
        YUM works with yum repositories which are under /etc/yum.repos.d -> *.repo

cd /etc/yum.repos.d
-----------------------
vi jenkins.repo
-----------------------
[jenkins]
name=description
baseurl/mirrorlist= online URL location where all the packages are stored
enabled=0/1
gpgcheck=0/1
gpgkeys=/etc/cert/jenkins.key

commands: yum install httpd -y              // Install latest package version
          yum install httpd-2.4* -y         // Install specific version of package 
          yum list                          // list all packages - installed/uninstalled
          yum list --installed              // list all installed packages
          yum list --installed | grep -i httpd  // filter and list installed package
          yum upgrade httpd -y               // upgrade package
          yum update -y                      // upgrade all package
          yum remove httpd -y                // Remove package 


-y confirmation yes/no

eg: zip, wget, at, bind-utils, net-tools, java, git, maven etc
    yum install zip -y
    yum install maven git -y

Backup and Restore:
=============================================================================================================================
      Backups are taken on softwares, files, directories, system logs, system messages, application logs, images etc
      Backups are taken for preserving the data for future reference and also it helps in case of disaster recovery.
      Further we can compress the backups, so we can easily transfer the backups to any location and also reduce the storage cost optimization.

1. TAR: Tape Archive
        Tar is an linux utility which comes in-built in any linux OS versions.
        Tar is used for taking backups on softwares, files, directories, system logs, system messages, application logs, images etc
        Using tar, we can further compress the objects.
        Tar has extension as .tar(bundle) and .tar.gz(bundle and compression)

--------------------------------------------------------------------
How to create/take backup without compression?
command: tar -cvf file.tar file1 file2 file3 file4
         tar -cvf file.tar file*
         tar -cvf file.tar *
--------------------------------------------------------------------
How to create/take backup with compression?
command: tar -cvzf file.tar.gz file1 file2 file3 file4
         tar -cvzf file.tar.gz file*
         tar -cvzf file.tar.gz *
--------------------------------------------------------------------
How to verify the backup ?
command: tar -tvf file.tar.gz
         tar -tvf file.tar
--------------------------------------------------------------------
How to restore/extract the backup ?
command: tar -xvf file.tar.gz
         tar -xvf file.tar
--------------------------------------------------------------------
-c create
-v verbose
-f force
-t display/verify
-x extract/restore

eg:  curl -O https://dlcdn.apache.org/maven/maven-3/3.9.11/binaries/apache-maven-3.9.11-bin.tar.gz

Super/Admin user: root user - most privileged user - non restricted user - default user in most of the Linux OS.
                  uid -  0
                  gid - 0
                  FN/comment - root
                  home directory - /root

                  uid - 1-999
                  gid - 1-999
                  FN/comment - ping, bin, daemon, system
                  home directory - /ping, /bin, /daemon, /system

Regular user: Normal user - Restricted user - john, smith, tomcat, sonar etc
                  uid - 1000 - soo on
                  gid - 1000 - soo on
                  FN/comment - "John Ronald" , "Smith france",  tomcat, sonar etc
                  home directory - /home/john, /home/smith, /home/tomcat, /home/sonar etc
                  SHELL - /bin/bash

Permissions: Permissions are provided on any object to users, groups and others.
=============================================================================================================================
1. change modification: Change modification is used for changing permissions like read, write and execute to restrict/allow using any object by users, groups and others via chmod command.

read         - view content or files/directories
write        - add/append/modify/delete content or files/directories
execute      - run program/script


read     - r - 4
write    - w - 2
execute  - x - 1

Least permission: 400
Highest permission: 777

Default permission for file: 644
user   group  others
rw-    r--     r--
420    400     400
 6      4       4

Default permission for directory: 755
user   group  others
rwx    r-x     r-x
421    401     401
 7      5       5


syntax: chmod [options]  [permissions] [file/directory]
   

command: chmod 400 sample.txt
         chmod 444 sample.txt
         chmod 666 sample.txt
         chmod 777 sample.txt

         chmod u=rw,g=rw,o=rw new-sample.txt
         chmod u=r.g=r,o=r new-sample.txt
         chmod u=rwx,g=rwx,o=rwx new-sample.txt  

         chmod +x test.sh
         chmod -x test.sh

         chmod -R 700 sample-dir
         chmod -R 777 dir1
  
         chmod -R 400 *
         chmod -R 400 /app/data
         chmod -R 400 /app/data/*

-R recursive
            
----------------------------------------------------------------------------------------------------------------------------
2. change ownership: Change ownership is used for transferring the ownership to other users and groups via chown command.

    syntax: chown [options] [user]:[group] [file/directory]

    command: chown john:john sample.txt
             chown john:root new-sample.txt
             chown root:john file.txt

             chown -R john:john test-dir
             chown -R john:john dir1

             chown -R willam:willam *
             chown -R willam:willam /app/data
             chown -R willam:willam /app/data/*

16. How to copy files/directories from one location to another location?
   
    syntax: cp [options] [src-location] [dest-location]

     -r recursively
     -f force
     -p preserve permissions


   command: cp file1 file2        // if file2 doesn't exist, file2 is created and then file1 contents are copied into file2
                                  // if file2 exist, file1 contents will copied into file2


            cp -r dir1 dir2      // if dir2 doesn't exist, dir2 is created and then dir1 contents are copied into dir2
                                 // if dir2 exist, dir1 itself is copied into dir2

            cp sample.txt dir2

            cp -r * /opt

            cp -r /opt/* /mnt/

17. How to move or rename files/directories from one location to another location?
   
    syntax: mv [src-location] [dest-location]

    command: mv file1 file2          // file1 will be renamed as file2
             mv dir1 dir2            // dir1 will be renamed as dir2

             mv sample.txt dir2     // move sample.txt into dir2

             mv /opt/* /tmp
             
             mv /mnt/* /opt
